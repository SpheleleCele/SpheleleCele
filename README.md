# Hi there, I'm Sphelele! 👋

I am an **MSc Biotechnology Candidate** specializing in bacterial genomics, computational workflows, and molecular microbiology. My current work focuses on decoding the genomic architectures and cellular mechanics that drive antimicrobial resistance (AMR).

---

## 🛠️ What I'm Building
* **ONT-Assembly-Circularization-Pipeline:** A Nextflow workflow engineered to take raw Oxford Nanopore long reads, construct high-fidelity *de novo* assemblies using Flye, circularize chromosomes/plasmids via Circlator, and automatically generate functional annotations using Prokka.

## 📚 What I'm Learning & Practicing
* **Bioinformatics & Pipeline Engineering:** Building reproducible data structures and automated pipelines using Nextflow, Snakemake, and High-Performance Computing (HPC) environments.
* **Data Processing:** Refining my Python and SQL skills to parse massive genomic datasets, optimize BLAST query outputs, and handle pangenome datasets (Roary, FastTree, GATK).
* **Wet Lab Assay Validation:** Translating computational findings into the lab via DNA extraction, PCR, agarose gel electrophoresis, and biochemical screening.
